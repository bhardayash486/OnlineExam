# Online Exam System
A Java Swing-based desktop application for conducting online examinations. 
This project was developed as a Semester 5 academic project and uses MySQL as the backend database.

# Features
Student Login
Admin Login
Add, Edit, and Delete Questions
Conduct Online Exams
Timer-based Examination
Automatic Result Calculation
View Student Scores
MySQL Database Integration

# Technologies Used
Java
Java Swing
JDBC
MySQL
NetBeans

# Requirements
JDK 8 or later
MySQL Server
Java IDE (NetBeans, Eclipse, or IntelliJ IDEA)

# Database Setup

1. Create a MySQL database.
2. Import the SQL file provided with the project.
3. Update the database connection details in the Java source code.

# How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/bhardayash486/javaCOde.git
   ```
2. Open the project in NetBeans or Eclipse.
3. Configure the MySQL database connection.
4. Build and run the project.
